# Software de terceiros / Third-party software

O Otavix Launcher usa / The Otavix Launcher uses:

| Projeto | Licença | Uso |
|---|---|---|
| [SDL 3](https://github.com/libsdl-org/SDL) 3.4.16 | zlib | janela, controles, áudio, diálogos, processos |
| [Dear ImGui](https://github.com/ocornut/imgui) 1.92.9b | MIT | interface |
| [toml++](https://github.com/marzer/tomlplusplus) 3.4.0 | MIT | perfis e configurações |
| [stb_image, stb_vorbis](https://github.com/nothings/stb) | MIT ou domínio público | imagens e OGG |
| [dr_mp3, dr_wav](https://github.com/mackron/dr_libs) | MIT-0 ou domínio público | MP3 e WAV |
| [Inter](https://rsms.me/inter/) 4.1 | SIL Open Font License 1.1 | fonte |

Dados usados pelo catálogo de pedidos de port / Data used by the port request catalog:

- Nomes e capas: [libretro-thumbnails](https://github.com/libretro-thumbnails) (thumbnails.libretro.com).
- PlayStation 3: [GameTDB](https://www.gametdb.com) (nomes e capas, art.gametdb.com).
- Xbox 360: lista de discos do [Redump](http://redump.org).

As capas são baixadas na hora, no PC do jogador, e pertencem aos seus donos. Nenhum jogo, arquivo de jogo ou arte de
jogo acompanha o launcher. / Covers are fetched on the player's PC and belong to their owners. No game, game file or
game art ships with the launcher.

God of War, inFAMOUS, Silent Hill, FIFA Street, Asura's Wrath e Dante's Inferno são marcas dos seus donos (Sony
Interactive Entertainment, Konami, Electronic Arts, Capcom). Este projeto não tem relação com eles. / These are
trademarks of their owners; this project is not affiliated with them.

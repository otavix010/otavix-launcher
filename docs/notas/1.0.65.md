**Português**
- **Python não reconhecido:** o botão "Conferir" da geração do God of War: Ascension agora também procura o Python nas pastas comuns de instalação e no registro do Windows, e não só no PATH (quem instalou o Python sem "Add python.exe to PATH" não conseguia avançar).
- **God of War: Ascension (atualização do port):** a geração não para mais quando a cópia do jogo é um arquivo sem pasta no caminho (etapa 2); o `build_portatil` funciona em pastas com parênteses ou espaços no nome (por exemplo "Jogo (USA)"); o MLAA das SPUs ficou mais leve (menos carga nas SPUs); o log do jogo agora diz quais controles ele achou (XInput, DualShock, DualSense) para ajudar nos reports de controle.

**English**
- **Python not recognized:** the "Check" button of God of War: Ascension's generation now also looks for Python in the usual install folders and in the Windows registry, not only in the PATH (people who installed Python without "Add python.exe to PATH" could not go on).
- **God of War: Ascension (port update):** generation no longer stops when the game copy is a file with no folder in its path (step 2); `build_portatil` works in folders with parentheses or spaces in the name (for example "Game (USA)"); the SPUs' MLAA is lighter (less SPU load); the game's log now says which controllers it found (XInput, DualShock, DualSense) to help with controller reports.

**Español**
- **Python no reconocido:** el botón "Comprobar" de la generación de God of War: Ascension ahora también busca Python en las carpetas habituales de instalación y en el registro de Windows, no solo en el PATH (quien instaló Python sin "Add python.exe to PATH" no podía avanzar).
- **God of War: Ascension (actualización del port):** la generación ya no se detiene cuando la copia del juego es un archivo sin carpeta en la ruta (paso 2); `build_portatil` funciona en carpetas con paréntesis o espacios en el nombre (por ejemplo "Juego (USA)"); el MLAA de las SPU es más ligero (menos carga en las SPU); el log del juego ahora dice qué mandos encontró (XInput, DualShock, DualSense) para ayudar con los reportes de mandos.

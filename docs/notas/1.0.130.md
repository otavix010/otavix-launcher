**Português**
- **Blade II:** o save state fica desligado por enquanto, porque carregar um estado na mesma sessão podia deixar texturas com defeito. Ele volta numa próxima versão, já corrigido; os saves normais do jogo continuam valendo. Clique em "Atualizar o port" para receber.

**English**
- **Blade II:** save states are turned off for now, because loading a state in the same session could leave textures broken. They come back in a later version, fixed; the game's own saves keep working. Click "Update the port" to get it.

**Español**
- **Blade II:** los save states quedan desactivados por ahora, porque cargar un estado en la misma sesión podía dejar texturas con defectos. Vuelven en una próxima versión, ya corregidos; las partidas guardadas normales del juego siguen funcionando. Haz clic en "Actualizar el port" para recibirlo.

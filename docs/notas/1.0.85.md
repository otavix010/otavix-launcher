**Português**
- **Instalação do jogo:** quando o Windows monta a .iso mas não dá letra de unidade a ela, o launcher agora copia o jogo mesmo assim (antes parava com "sem letra de unidade").
- **Escolher o disco de novo:** se a pasta ou o arquivo do jogo escolhido antes não existe mais (movido, apagado ou num HD desligado), o launcher avisa na hora, antes de rodar as ferramentas, em vez de falhar no fim da geração.
- **Troca de cópia do jogo:** ao extrair o jogo de novo, a cópia anterior só é apagada depois que a nova está no lugar.
- **Textos:** o caminho C:\OtavixPorts aparecia sem a barra em algumas mensagens.

**English**
- **Game install:** when Windows mounts the .iso but gives it no drive letter, the launcher now copies the game anyway (before, it stopped with "no drive letter").
- **Pick the disc again:** if the game's folder or file picked earlier no longer exists (moved, deleted or on a drive that is off), the launcher says so right away, before running the tools, instead of failing at the end of the generation.
- **Replacing the game copy:** when the game is unpacked again, the earlier copy is only deleted once the new one is in place.
- **Texts:** the path C:\OtavixPorts showed without its backslash in some messages.

**Español**
- **Instalación del juego:** cuando Windows monta la .iso pero no le da letra de unidad, el launcher ahora copia el juego igualmente (antes se detenía con "sin letra de unidad").
- **Elegir el disco de nuevo:** si la carpeta o el archivo del juego elegido antes ya no existe (movido, borrado o en un disco apagado), el launcher avisa en el acto, antes de ejecutar las herramientas, en lugar de fallar al final de la generación.
- **Cambio de la copia del juego:** al extraer el juego otra vez, la copia anterior solo se borra cuando la nueva ya está en su lugar.
- **Textos:** la ruta C:\OtavixPorts aparecía sin la barra en algunos mensajes.

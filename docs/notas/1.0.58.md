**Português**
- **God of War: Ascension, geração:** a geração parava com "Visual Studio Build Tools com Clang não encontrado" ou "vcvars64.bat não é reconhecido" em PCs com o Visual Studio 2026 (ou um Visual Studio sem o C++ completo). Agora o launcher oferece o botão de instalar o Build Tools e o gerador instala sozinho o Visual Studio 2022 Build Tools (o Windows pede permissão) e continua.

**English**
- **God of War: Ascension, generation:** it stopped with "Visual Studio Build Tools with Clang not found" or "vcvars64.bat is not recognized" on PCs with Visual Studio 2026 (or a Visual Studio without the full C++ tools). Now the launcher offers the Build Tools install button and the generator installs Visual Studio 2022 Build Tools by itself (Windows asks for permission) and goes on.

**Español**
- **God of War: Ascension, generación:** se detenía con "Visual Studio Build Tools con Clang no encontrado" o "vcvars64.bat no se reconoce" en PCs con Visual Studio 2026 (o un Visual Studio sin el C++ completo). Ahora el launcher ofrece el botón de instalar el Build Tools y el generador instala solo Visual Studio 2022 Build Tools (Windows pide permiso) y continúa.

**Português**
- **inFAMOUS Second Son (port 1.0.3):** se o jogo fechar logo ao abrir com a Geração de Quadros (Streamline/DLSS-G), o port reabre sozinho sem ela e passa a abrir sem ela (apague user\framegen.off, ou defina SHADPS4_FG_FORCE=1, para tentar de novo). Quedas sem tratamento gravam user\log\crash.txt (módulo e endereço) e crash.dmp, e o report do jogo agora leva o crash.txt e o entrada.txt.
- **God of War: Ascension:** o gerador compila com mais robustez (instala o Windows 11 SDK quando falta e usa um PATH limpo), e o jogo registra mais informações quando a tela fica preta.

**English**
- **inFAMOUS Second Son (port 1.0.3):** if the game closes right on start with Frame Generation (Streamline/DLSS-G), the port reopens it by itself without it and keeps opening without it (delete user\framegen.off, or set SHADPS4_FG_FORCE=1, to try again). Unhandled crashes write user\log\crash.txt (module and address) and crash.dmp, and the game's report now carries crash.txt and entrada.txt.
- **God of War: Ascension:** the generator builds more reliably (installs the Windows 11 SDK when missing and uses a clean PATH), and the game logs more detail when the screen turns black.

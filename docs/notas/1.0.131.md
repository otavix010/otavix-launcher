**Português**
- **Linux:** na página de um jogo que não roda no Linux (por exemplo os de PSP, "Em breve"), o launcher não mostra mais "Criar atalho na área de trabalho" nem a dica "Para fechar o jogo". Na vista do Windows dentro do Linux, o botão agora diz "Só no Windows" em vez de "Port não instalado".

**English**
- **Linux:** on the page of a game that does not run on Linux (for example the PSP ones, "Coming soon"), the launcher no longer shows "Make a desktop shortcut" or the "To close the game" hint. In the Windows view inside Linux, the button now says "Windows only" instead of "Port not installed".

**Español**
- **Linux:** en la página de un juego que no funciona en Linux (por ejemplo los de PSP, "Próximamente"), el launcher ya no muestra "Crear acceso directo en el escritorio" ni la pista "Para cerrar el juego". En la vista de Windows dentro de Linux, el botón ahora dice "Solo en Windows" en lugar de "Port no instalado".

**Português**
- **Instalação do Visual Studio Build Tools (todos os ports que compilam):** se o Build Tools já estiver instalado mas faltar o Clang, o CMake ou as ferramentas de C++, o launcher agora acrescenta os componentes que faltam pelo instalador do Visual Studio (modificar), em vez de dizer que já está instalado e deixar a geração falhar. Antes era preciso abrir o Visual Studio Installer e marcar à mão.

**English**
- **Visual Studio Build Tools install (every port that compiles):** if Build Tools is already installed but Clang, CMake or the C++ tools are missing, the launcher now adds the missing components through the Visual Studio installer (modify), instead of reporting it as installed and letting the generation fail. Before, you had to open the Visual Studio Installer and tick them by hand.

**Español**
- **Instalación de Visual Studio Build Tools (todos los ports que compilan):** si Build Tools ya está instalado pero faltan Clang, CMake o las herramientas de C++, el launcher ahora añade los componentes que faltan con el instalador de Visual Studio (modificar), en lugar de darlo por instalado y dejar que la generación falle. Antes había que abrir el Visual Studio Installer y marcarlos a mano.

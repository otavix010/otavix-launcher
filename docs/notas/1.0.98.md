**Português**
- **inFAMOUS Second Son:** o launcher não aceita mais um .iso, um .pkg de PS3 ou a pasta de um jogo de PS3 como o jogo; ele avisa o que é e pede o jogo de PS4 (.pkg ou a pasta extraída com o eboot.bin).

**English**
- **inFAMOUS Second Son:** the launcher no longer takes an .iso, a PS3 .pkg or a PS3 game's folder as the game; it says what it is and asks for the PS4 game (.pkg files or the extracted folder with eboot.bin).

**Español**
- **inFAMOUS Second Son:** el launcher ya no acepta un .iso, un .pkg de PS3 ni la carpeta de un juego de PS3 como el juego; avisa qué es y pide el juego de PS4 (.pkg o la carpeta extraída con eboot.bin).

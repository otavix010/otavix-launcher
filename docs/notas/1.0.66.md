**Português**
- **inFAMOUS Second Son (port 1.0.5):** se o jogo fechar logo ao abrir (erro 0xC0000005 dentro do carregador do Vulkan do Windows, causado em geral por camadas de overlay ou captura como OBS, Afterburner/RTSS, Steam, Discord, Epic ou ReShade), o port reabre sozinho com essas camadas desligadas e, se resolver, passa a abrir assim (apague user\camadas.off para voltar). Só depois tenta sem a geração de quadros. O relatório de queda e o log registram cada tentativa, e o log avisa quando a cópia do jogo não é a CUSA00004.

**English**
- **inFAMOUS Second Son (port 1.0.5):** if the game closes right on start (error 0xC0000005 inside Windows' Vulkan loader, usually caused by overlay or capture layers such as OBS, Afterburner/RTSS, Steam, Discord, Epic or ReShade), the port reopens it by itself with those layers off and, if that fixes it, keeps opening that way (delete user\camadas.off to go back). Only then does it try without Frame Generation. The crash report and the log record each attempt, and the log warns when the game copy is not CUSA00004.

**Español**
- **inFAMOUS Second Son (port 1.0.5):** si el juego se cierra al abrir (error 0xC0000005 dentro del cargador de Vulkan de Windows, causado en general por capas de overlay o captura como OBS, Afterburner/RTSS, Steam, Discord, Epic o ReShade), el port lo reabre solo con esas capas desactivadas y, si lo arregla, sigue abriendo así (borra user\camadas.off para volver). Solo después prueba sin la Generación de cuadros. El informe de cierre y el log registran cada intento, y el log avisa cuando la copia del juego no es CUSA00004.

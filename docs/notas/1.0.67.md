**Português**
- **God of War: Ascension, nova opção "Versão do executável"** (Opções avançadas > Jogo): Automático (o padrão, escolhe pelo seu processador), Portátil (AVX2, roda em qualquer processador compatível) ou Nativa (otimizada para o seu processador). Se o jogo fechar logo ao abrir (erro 0xC000001D) ou se comportar mal, experimente a Portátil. Ao trocar de versão o launcher avisa que é preciso gerar de novo e oferece o botão "Gerar de novo"; só a build escolhida é compilada, em poucos minutos.
- O relatório de problemas passa a dizer qual versão do executável estava escolhida, qual foi usada e por quê.

**English**
- **God of War: Ascension, new "Executable version" option** (Advanced options > Game): Automatic (the default, picks by your processor), Portable (AVX2, runs on any compatible processor) or Native (tuned for your processor). If the game closes right away (error 0xC000001D) or misbehaves, try Portable. When you change it the launcher says the game must be made again and offers a "Make it again" button; only the chosen build is compiled, in a few minutes.
- The problem report now says which executable version was chosen, which one was used and why.

**Português**
- **Linux:** atualizar ports funciona sem o bsdtar (Ubuntu, Debian e outras distribuições): o launcher usa o tar e o unzip do sistema. Quando faltar alguma ferramenta, ele diz qual pacote instalar.
- **Linux:** instalar mods e pacotes de shaders também deixou de chamar o programa do Windows.

**English**
- **Linux:** updating ports works without bsdtar (Ubuntu, Debian and other distributions): the launcher uses the system's tar and unzip. When a tool is missing, it tells you which package to install.
- **Linux:** installing mods and shader packs no longer calls the Windows program either.

**Português**
- **Versão para Linux e SteamOS:** o Otavix Launcher agora roda no Linux (Steam Deck, Legion Go S e outros aparelhos com SteamOS), com a mesma interface do Windows. Por enquanto baixa e instala o God of War: Betrayal; o inFAMOUS Second Son para Linux vem em seguida. Baixe o `Otavix-Launcher-<versão>-linux-x64.tar.gz`, extraia e execute `instalar.sh` para criar a entrada no menu.
- **Atualização do launcher no Linux:** o launcher baixa e aplica a versão nova sozinho.

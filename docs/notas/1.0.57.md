**Português**
- **O jogo que já está na pasta dos discos é achado sozinho:** se você definiu a "Pasta dos discos" nas configurações e o jogo (por exemplo o inFAMOUS Second Son, já extraído) está nela ou numa pasta dentro dela, o launcher usa esse jogo sem você escolher nada.
- **Administração:** a lista de reports e de pedidos de ports se atualiza sozinha a cada minuto com a aba aberta.

**English**
- **A game already in the discs folder is found by itself:** if you set the "Discs folder" in the settings and the game (inFAMOUS Second Son, already extracted, for example) is in it or in a folder inside it, the launcher uses that game without you picking anything.
- **Administration:** the list of reports and port requests looks itself up every minute while the tab is open.

**Español**
- **El juego que ya está en la carpeta de discos se encuentra solo:** si definiste la "Carpeta de los discos" en los ajustes y el juego (por ejemplo inFAMOUS Second Son, ya extraído) está en ella o en una carpeta dentro, el launcher usa ese juego sin que elijas nada.
- **Administración:** la lista de reports y de pedidos de ports se actualiza sola cada minuto con la pestaña abierta.

**English**
- **inFAMOUS Second Son (PS4) comes to the launcher:** a new "PlayStation 4" library with the PC port (the shadPS4 emulator tuned for the game: fixed effects, much more fps in the city and DLSS Frame Generation on RTX 40 and 50). Pick your already extracted game folder (CUSA00004) and play. The launcher and the port ship no game files. The Linux/SteamOS version is a manual download for now, and the build's source code (GPL) is on the server.
- **Xbox 360 games from an extracted disc:** you can now pick the already extracted disc folder (not just the .iso) and play through the launcher; fixed the "invalid characters in the path" error when the folder ends in a backslash.
- Includes everything from 1.0.53: Play without freezing, the launcher problem report button (Settings > About), F10 back in the 360 games and FIFA Street 2, the 360 SDK from the launcher's server and the God of War: Ascension fixes (generation without the PATH and permission errors, FFmpeg from the server).

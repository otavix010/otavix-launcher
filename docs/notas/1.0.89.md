**Português**
- **God of War: Ascension, opção "Resolução":** os nomes agora mostram o multiplicador e a tela em que cada opção vira supersampling (por exemplo, "1440p (2x; supersampling em telas 1080p)"), para ficar claro o que cada uma faz.
- **God of War: Ascension, engine 0.11.6:** os downloads do gerador (engine, FFmpeg e update da Sony) são retomados nas quedas de conexão; uma pasta PS3_GAME antiga que atrapalha a geração é renomeada sem apagar nada; controles de PS4 "paralelos" passam a ser reconhecidos; o Python da Microsoft Store é tratado; e as mensagens de cópia reduzida, de processadores sem AVX2 e do bloqueio do Windows (Device Guard) ficaram mais claras.

**English**
- **God of War: Ascension, "Resolution" option:** the names now show the multiplier and the screen where each option becomes supersampling (for example, "1440p (2x; supersampling on 1080p screens)"), so it is clear what each one does.
- **God of War: Ascension, engine 0.11.6:** the generator's downloads (engine, FFmpeg and the Sony update) resume after dropped connections; an old PS3_GAME folder that blocks generation is renamed without deleting anything; "third-party" PS4 controllers are now recognized; the Microsoft Store Python is handled; and the messages for reduced copies, processors without AVX2 and the Windows block (Device Guard) are clearer.

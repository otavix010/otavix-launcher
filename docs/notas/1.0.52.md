**Português**
- **Downloads pelo servidor do launcher:** o launcher, o código dos ports, os pacotes de shaders e as novidades agora vêm primeiro do servidor do próprio launcher, com o GitHub como alternativa. Instalar, gerar e atualizar os jogos volta a funcionar normalmente.
- Inclui a novidade da 1.0.51: a opção "Compartilhar o desempenho (anônimo)" também na aba Desempenho de cada jogo.

**English**
- **Downloads from the launcher's server:** the launcher, the ports' code, the shader packs and the release notes now come first from the launcher's own server, with GitHub as a fallback. Installing, generating and updating the games works normally again.
- Includes 1.0.51's change: the "Share performance (anonymous)" option also on each game's Performance tab.

**Español**
- **Descargas desde el servidor del launcher:** el launcher, el código de los ports, los paquetes de shaders y las novedades ahora vienen primero del servidor del propio launcher, con GitHub como alternativa. Instalar, generar y actualizar los juegos vuelve a funcionar con normalidad.
- Incluye la novedad de la 1.0.51: la opción "Compartir el rendimiento (anónimo)" también en la pestaña Rendimiento de cada juego.

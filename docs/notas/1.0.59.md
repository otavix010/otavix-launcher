**Português**
- **Escolher o disco de novo:** a página de um jogo já gerado agora tem sempre o botão "Escolher o disco de novo" (antes só aparecia quando a pasta do disco sumia). Ele refaz só a ligação com o disco, sem gerar tudo outra vez.
- **inFAMOUS Second Son:** o port 1.0.2 avisa com uma mensagem clara quando o caminho do jogo é um .iso, .pkg ou arquivo compactado (o emulador precisa da pasta extraída, com o eboot.bin). O report do jogo agora leva também o log do emulador.

**English**
- **Pick the disc again:** the page of an already made game now always has the "Pick the disc again" button (it used to show only when the disc's folder was gone). It redoes just the link to the disc, without making everything again.
- **inFAMOUS Second Son:** port 1.0.2 gives a clear message when the game's path is an .iso, .pkg or archive (the emulator needs the unpacked folder with eboot.bin). The game's report now carries the emulator's log too.

**Español**
- **Elegir el disco de nuevo:** la página de un juego ya generado ahora siempre tiene el botón "Elegir el disco de nuevo" (antes solo aparecía cuando la carpeta del disco había desaparecido). Rehace solo el enlace con el disco, sin generar todo otra vez.
- **inFAMOUS Second Son:** el port 1.0.2 avisa con un mensaje claro cuando la ruta del juego es un .iso, .pkg o archivo comprimido (el emulador necesita la carpeta extraída, con eboot.bin). El reporte del juego ahora lleva también el log del emulador.

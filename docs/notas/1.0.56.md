**Português**
- **Instalar o jogo ficou igual para todos:** você mostra a pasta (ou o arquivo baixado) e o launcher localiza o jogo, descompacta se precisar e segue. Se a pasta só tem o download (.7z, .zip, .rar), ele descompacta o arquivo que achar ali.
- **inFAMOUS Second Son:** agora entende os arquivos .pkg do PS4 (jogo, update e DLC). Mostre a pasta com os .pkg e o launcher extrai tudo sozinho; a ferramenta que abre o .pkg é baixada do servidor do launcher na primeira vez.
- O passo a passo "instalação manual" saiu: são só dois botões, "Escolher o arquivo baixado" e "Mostrar a pasta do jogo" (também dá para arrastar para a janela).

**English**
- **Installing a game is the same for all of them:** you show the folder (or the downloaded file) and the launcher finds the game, unpacks it if needed and goes on. If the folder only holds the download (.7z, .zip, .rar), it unpacks the file it finds there.
- **inFAMOUS Second Son:** now understands the PS4 .pkg files (game, update and DLC). Show the folder with the .pkg files and the launcher extracts everything by itself; the tool that opens .pkg is downloaded from the launcher's server the first time.
- The "manual install" steps are gone: just two buttons, "Pick the downloaded file" and "Show the game's folder" (you can also drag onto the window).

**Español**
- **Instalar el juego es igual para todos:** muestras la carpeta (o el archivo descargado) y el launcher encuentra el juego, lo descomprime si hace falta y sigue. Si la carpeta solo tiene la descarga (.7z, .zip, .rar), descomprime el archivo que encuentre.
- **inFAMOUS Second Son:** ahora entiende los archivos .pkg de PS4 (juego, update y DLC). Muestra la carpeta con los .pkg y el launcher extrae todo solo; la herramienta que abre el .pkg se descarga del servidor del launcher la primera vez.
- Los pasos de la "instalación manual" salieron: solo dos botones, "Elegir el archivo descargado" y "Mostrar la carpeta del juego" (también se puede arrastrar a la ventana).

**Português**
- **Falta de memória no God of War: Ascension:** quando o jogo fecha porque faltou memória, o aviso do launcher agora explica o motivo e o que fazer (aumentar o arquivo de paginação do Windows e fechar outros programas).
- **Linux e SteamOS:** fechar o jogo pelo controle (Back + Start) agora funciona, e o processo é encerrado se o jogo não fechar sozinho.

**English**
- **Out of memory in God of War: Ascension:** when the game closes because memory ran out, the launcher's notice now explains the reason and what to do (increase the Windows paging file and close other programs).
- **Linux and SteamOS:** closing the game from the controller (Back + Start) now works, and the process is ended if the game does not close by itself.

**Português**
- **Pasta do jogo errada:** quando o caminho do jogo é um .iso, um .pkg, um arquivo compactado, um jogo de PS3 ou uma pasta sem o eboot.bin, o port mostra um aviso no idioma do sistema explicando o que escolher, em vez de fechar com o erro 1.

**English**
- **Wrong game folder:** when the game's path is an .iso, a .pkg, an archive, a PS3 game or a folder without eboot.bin, the port shows a message in the system's language explaining what to pick, instead of closing with error 1.

**Español**
- **Carpeta del juego equivocada:** cuando la ruta del juego es un .iso, un .pkg, un archivo comprimido, un juego de PS3 o una carpeta sin eboot.bin, el port muestra un aviso en el idioma del sistema explicando qué elegir, en lugar de cerrarse con el error 1.

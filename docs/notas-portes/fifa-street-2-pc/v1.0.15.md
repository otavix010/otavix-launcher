**Português**
- **Teclado e mouse:** dá para jogar sem controle. W A S D movem, o mouse faz os dribles (analógico direito), K/Enter/clique esquerdo passa, L/Backspace/clique direito chuta, J ou F passe alto, I ou R exibição, Espaço e Shift são os gatilhos (Shift = turbo), setas = direcional, Esc pausa. As teclas podem ser trocadas na tabela [keys] do settings.toml (ou na página Controles do launcher 1.0.97); a lista completa está no README (report 1302).
- **Diagnóstico:** o registro de um fechamento inesperado agora traz mais dados para acharmos a causa (report 1299).

**English**
- **Keyboard and mouse:** the game can be played without a controller. W A S D move, the mouse does the tricks (right stick), K/Enter/left click passes, L/Backspace/right click shoots, J or F high pass, I or R show off, Space and Shift are the triggers (Shift = turbo), arrows = D-pad, Esc pauses. Keys can be changed in the [keys] table of settings.toml (or on the Controls page of launcher 1.0.97); the full list is in the README (report 1302).
- **Diagnostics:** the log of an unexpected close now carries more data for us to find the cause (report 1299).

**Español**
- **Teclado y ratón:** se puede jugar sin mando. W A S D mueven, el ratón hace los regates (stick derecho), K/Enter/clic izquierdo pasa, L/Retroceso/clic derecho tira, J o F pase alto, I o R lucirse, Espacio y Mayús son los gatillos (Mayús = turbo), flechas = cruceta, Esc pausa. Las teclas se cambian en la tabla [keys] de settings.toml (o en la página Controles del launcher 1.0.97); la lista completa está en el README (report 1302).
- **Diagnóstico:** el registro de un cierre inesperado ahora trae más datos para encontrar la causa (report 1299).

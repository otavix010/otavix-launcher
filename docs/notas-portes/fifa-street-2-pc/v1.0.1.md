**Português**
- Diagnóstico de crashes: se o jogo fechar com erro, o log registra onde foi e, se a placa de vídeo parar de responder, o motivo e os últimos comandos. Os 3 logs anteriores ficam guardados. Na primeira abertura depois de atualizar, o código do jogo é preparado de novo (alguns segundos a um minuto).

**English**
- Crash diagnostics: if the game closes with an error, the log records where, and if the graphics card stops responding, why and its last commands. The 3 previous logs are kept. On the first start after updating, the game's code is prepared again (a few seconds to a minute).

**Español**
- Diagnóstico de cierres: si el juego se cierra con error, el registro anota dónde y, si la tarjeta gráfica deja de responder, el motivo y sus últimos comandos. Se guardan los 3 registros anteriores. En la primera apertura tras actualizar, el código del juego se prepara de nuevo (de unos segundos a un minuto).

**Português**
- O VRR agora vem desligado por padrão. A opção VRR (G-SYNC / FreeSync) continua no Vídeo: ligue se o seu monitor tiver G-SYNC ou FreeSync. Desligado, o jogo espera a tela (vsync), sem rasgos. Quem já tinha ligado continua com ela ligada.

**English**
- VRR is now off by default. The VRR (G-SYNC / FreeSync) option is still under Video: turn it on if your monitor has G-SYNC or FreeSync. Off, the game waits for the screen (vsync), with no tearing. If you had turned it on, it stays on.

**Español**
- El VRR ahora viene desactivado por defecto. La opción VRR (G-SYNC / FreeSync) sigue en Vídeo: actívala si tu monitor tiene G-SYNC o FreeSync. Desactivado, el juego espera a la pantalla (vsync), sin rasgaduras. Si ya la tenías activada, sigue activada.
